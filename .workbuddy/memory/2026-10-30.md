## 全站清理界面里的内部信息（接口路径 / DTO 字段 / 会话 ID / 供应商名）
- 原则：**用户界面只出现用户能懂的话**。接口路径、`@/api/xxx.fetchYyy`、DTO 字段名、`openapi/schema/联调/桩` 这类词只能留在代码注释里，禁止出现在模板文案、提示语、tooltip、placeholder、表头、空态里。
- 错误提示统一改成「业务对象 + 动作」的写法：`describeError('作业列表加载', e)` → 「作业列表加载失败：xxx」；`apiHint(e, '设置保存')`。不要再把 apiPath 拼进文案。
- 占位/未上线统一用「暂未开放 / 即将开放 / 敬请期待」，不要写「接口预留：后端未提供 xxx」。
- 已清理范围：QaView、AccountView、AdminDashboard、Backup、ClassManage、DatasetUpload、KnowledgeManage、LogAudit、SystemSettings、UserManage、WeightConfig、ChapterDetail、ChapterList、Report、StudentDashboard、WrongBook、Practice/PracticeSolve、CodeRecord、Homework、Intervention、PptTemplate、Settings、AdminRegisterCard、stores/prepare。
- 顺带修掉的真 bug：`ClassManageView.vue` 删除按钮 `:title="`删除「${row.className}」"` 少了收尾反引号，导致模板字面量未闭合、vue-tsc 报 TS1160 连带整页编译失败。凡改模板里的反引号插值，改完必须跑一次 vue-tsc。
- 供应商名也算内部信息：界面上的「Dify」一律换成「知识库」，`Dify 文档` → `知识库文档`。
