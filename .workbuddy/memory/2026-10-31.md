# 2026-10-31

## 作业作答按新 openapi 适配：提交改用题库 ID（修掉一个真 bug）
- 旧实现把「作业题目快照 ID」原样当 `answers[].questionId` 提交，新契约下这会被后端判成 `code=1001`（题目不属于该作业）。已改为：
  - 拉题干：`GET /student/question?questionId=` 仍是**快照 ID**（不变）；
  - 提交：`questionId` 取题目返回的 `questionId`（**题库 ID**，`exam_question.id`），并额外带 `snapshotId`（=题目返回的 `id`），让错题钉在发布那一版题上。
- 老快照可能缺题库 ID（`questionId` 为 null）：该题作答区下方给一条「暂不支持在线提交」的提示，提交时把它挑出来单独提示，不让整份提交失败（`blockedCount`）。
- 新字段落地：`StudentHomeworkQuestion` 增加 `questionId` / `codeFramework` / `requirements` / `hints`；`HomeworkAnswer` 增加可选 `snapshotId`；`api/exam.ts` 新增 `toStringListOrNull()`，未配置的要求/提示一律给 null。
- 页面增强（`HomeworkSolveView.vue`）：题干下展示「作答要求」；「提示」逐条展开（`再给一条提示` / `收起提示`，不计分）；编程题把 `codeFramework` 传给 AnswerArea 初始化编辑器，并因为现在拿得到题库 ID，开启了「运行代码 / 智能纠错」（`showCodeTools` + `runQuestionId` + `chapterId`）。
- 题量口径改为 `questionIds.length`（`questionCount` 可能与发布统计不一致，按文档建议）。
- 校验：`vue-tsc --noEmit` 通过、`vite build` ✓ built in 3.07s。

## 作业续做：草稿保存 / 进度恢复 / 交卷语义升级
- 新接口：`POST /api/exam/homework/draft`（草稿，不判卷）、`GET /api/exam/homework/my-answers`（回填）；`submit` 语义升级为「本次作答转正 + 其余草稿一并转正 + 全量重批」。
- `types/exam.ts` 新增 `HomeworkDraftRequest` / `HomeworkDraftResult` / `HomeworkAnswerRecord` / `HomeworkAnswers`；`api/exam.ts` 新增 `saveHomeworkDraft`、`fetchMyHomeworkAnswers`（`expired`/`canSubmit` 后端给 null 时保持 null，别当 false）。
- 作答页（`HomeworkSolveView.vue`）：
  - 进入时 `brief` 与 `my-answers` 并行拉，后者失败不影响答题（只失去回填）。回填按 `snapshotId` 直接挂；`snapshotId` 为 0 的记录按 `questionId` 暂存，题目懒加载完再挂（`mountPendingAnswer`）。
  - 编辑后 3s 节流 `POST /draft`，只累积本次变化的题；切后台（`visibilitychange`）与卸载时补一次 flush，`beforeunload` 有未保存改动时提示。
  - 已交卷题只读（给 `AnswerArea` 新增 `readonly` prop），右上角「修改作答」解锁；已交题的改动不存草稿、只在重新交卷时生效。
  - 交卷 payload 只发「有改动/有内容」的题；**本地清空但后端有草稿行的题必须显式传空串**，否则交卷时「剩余草稿转正」会把清空前的旧内容当有效答案。
  - 顶部显示草稿状态（待保存/保存中/已保存 HH:mm/失败），题号导航区分 已交卷（绿）/草稿（灰）/未答。
- 列表页 `HomeworkView.vue`：不再用 `canSubmit` 拦入口，已截止也能进来回看/续写草稿，按钮文案切成「查看作答」。
- 校验：`vue-tsc --noEmit` 通过、`vite build` ✓ built in 2.31s。
